# SimpleCalculator


A basic calculator application built using simple programming concepts.
This project can perform basic arithmetic operations such as:

* Addition
* Subtraction
* Multiplication
* Division

## Features

* Easy to use
* Lightweight and fast
* Beginner-friendly project
* Clean and simple interface

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Clone this repository:

```bash
git clone https://github.com/IT25103812/SimpleCalculator.git
```

2. Open the project folder.

3. Run the `index.html` file in your browser.

## Project Purpose

This project was created for learning and practicing basic web development and calculator logic.
